# 订单块边界局部反应实验 v3.1

Base: `7a0447bbd49d55778b3eb214fdaa6a47b09be566`

本实验是**局部边界预测实验**，不是严格因果断点实验。
不声称"订单块产生因果效应"。

核心识别（与上一版一致，未改动）：

```text
ob_margin_R = penetration_depth_R - nearest_ob_distance_R
ob_margin_R < 0  -> 还没进入最近的反向 OB
ob_margin_R >= 0 -> 已进入最近的反向 OB
```

---

## 一句话结论

> **在 `ob_margin_R = 0` 边界附近，没有发现"刚进入订单块"带来的局部概率跃升。**
> reclaim 概率从 −0.5R 到 +0.5R 是**平滑波动**，0 附近没有跳变。

> ### ⚠️ 结论修订（2026-09-11，由 v3.2 审计触发）
>
> 本文件原判定 **C. 无稳定订单块局部增量**，现**修订为 D. 局部识别条件不成立**。
>
> 修订依据（均为本文件自身已记录的事实）：
> 1. 预注册连续性 Gate **FAIL**：总体最大 SMD 0.3341（>0.15），
>    关键变量 `penetration_depth_R` SMD 0.1242（>0.10）。
>    合同明确规定 Gate 不成立即不得把左右两侧当作可比局部样本。
> 2. 实现语义错误：`D = (x >= 0)` 把 `ob_margin_R == 0`（**恰好碰到边界**
>    而非进入 OB）归入右侧。exact_zero 达 1,100 个，
>    而 ±0.20R 右侧总共 2,022 个 —— **右侧超过一半其实是"碰边界"**，
>    所谓"刚没进入 vs 刚进入"并未真正实现。
> 3. 多周期趋势未真正接入：`attach_trend_multi` 调用的 `_trend()`
>    恒返回 `trend_struct_1h`，导致 `trend_struct_5m/15m` 全为 UNKNOWN，
>    `trend_1h_vs_15m` 有效样本为 0。多周期条件效应**实际上未检验**。
>
> 因此：
> ```text
> 描述性结果没有显示明显边界跳跃，
> 但因为连续性 Gate FAIL，
> 不能正式据此否定 OB 的局部预测价值。
> ```
>
> 原结果**保留不删除**，作为探索性记录。正式接续实验见
> `research/analysis_results/liquidity_ob_boundary_v3_2/`。

## 二、连续性 Gate —— **FAIL**

| 门 | 要求 | 实测 | 结果 |
|---|---|---:|:--:|
| numeric 全部 | \|SMD\| ≤ 0.15 | **0.3341** | ❌ |
| numeric 关键三项 | \|SMD\| ≤ 0.10 | **0.1242** | ❌ |
| 分类变量 | 占比差 ≤ 8pp | 7.89 | ✅ |

最不平衡的变量：

| variable | SMD |
|---|---:|
| atr_rel_pre | **0.3341** |
| level_age_log1p | 0.2677 |
| volume_z_t0 | −0.1750 |
| bar_range_R | −0.1306 |
| **penetration_depth_R（关键）** | **−0.1242** |
| close_beyond_R（关键） | −0.0901 |
| pre_range_12_R（关键） | 0.0850 |

**关键变量 `penetration_depth_R` 仍差 0.1242**：即使在 ±0.20R 这么窄的带内，
右侧（刚进入 OB）的扫破深度依然系统性地更深。
这正是你警告过的混淆 —— **"要进入 OB 就得扫得更深"在数学上无法完全消除。**

分类变量最差：symbol=I 差 7.89pp（勉强通过）。

→ **`LOCAL_CONTEXT_CONTINUITY_FAIL`**：总体 τ 不做强解释。
按 §13 第二步，改为在预注册 subgroup 内单独重跑同一边界。

## 三、边界密度 —— **存在价格离散质量点**

| 项 | 值 |
|---|---:|

| exact_zero_share | **4.39%** |
| 左侧唯一 margin 值 | 4,355 |
| 右侧唯一 margin 值 | 2,314 |

**有 1,100 个事件（4.39%）的 `ob_margin_R` 恰好等于 0** ——
即价格极值精确落在 OB 近端边界上。这是**价格离散造成的质量点**，
已记录为 inference limitation，未删除。

不过 [−0.05,0) 有 77 个、[0,0.05] 有 82 个，两侧紧邻区间样本量接近，
没有出现单侧异常巨量堆积。

5. **刚没进入 OB 的 reclaim？** 0.7617。

## 十一、已知限制

1. `ob_margin_R = 0` 存在 4.39% 的价格离散质量点。
2. 连续性 Gate 未通过：右侧扫破深度系统性更深（SMD 0.1242），
   这是"进入 OB 必须扫更深"带来的结构性残留。
3. 边界左侧样本（856）远少于右侧（2,022），局部估计左侧方差较大。
4. `atr_rel_pre` SMD 0.3341，边界两侧波动率环境不同。
5. 1h OB、RETESTED、1h liquidity 等 subgroup 样本不足，未做推断。
6. F1–F4 各折仅 250–350 个事件，不足以判断时间稳定性。
7. 未做多重检验校正；14 个预注册单元中出现 1 个显著属预期范围内。
8. 同价位 liquidity 使用严格数值相等（无 ATR 邻近阈值），
   可能低估真实的价位聚集。
9. 未执行 Landmark B、未做机器学习、未做收益回测。
