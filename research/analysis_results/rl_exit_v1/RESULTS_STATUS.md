# RL 动态退出 v1 结果状态说明

## 第一版结果（rl_overall.csv 历史版本）—— 口径错误，已修正

第一版的 `累计收益 14.9153` / `夏普率 1.5425` **口径错误，禁止引用**。

两个问题：

1. **日聚合只覆盖已交易事件**：未交易事件未以 0 计入日平均，
   机会集被缩小，夏普与累计收益被系统性放大。
2. **`交易次数` 用 `realized != 0` 统计**：收益恰为 0 的交易被漏计
   （简化C 实际 1681 笔，旧口径只报 1663 笔）。

## 修正后（当前版本，VALID）

统一口径：

- `opportunity_curve_cumulative_R` = **每日机会集等权曲线**累计值
  （当日所有合格机会：交易取实际收益、不交易取 0，再等权平均）。
- `trade_total_R` = 实际交易收益直接求和。
- `夏普率` / `最大回撤` 一律基于机会集曲线。
- `交易次数` = 实际执行交易的事件数（收益为 0 仍计入）。

一致性校验（已通过）：修正后「固定退出」= 简化C =
`opportunity_curve_cumulative_R 2.2933 / 夏普率 1.4395 / PF 1.1032`，
与 `m3_direction_target/m3dt_main.csv` 完全一致。

## 修正后结论：第一版动态退出失败

| 模型 | 固定退出夏普 | 动态退出夏普 | 差值 |
|---|---:|---:|---:|
| 线性 | 1.4395 | 1.1915 | −0.2480 |
| LightGBM | 1.4395 | 0.8227 | −0.6168 |
| XGBoost | 1.4395 | 0.4936 | −0.9459 |

三个模型全部为负。但 M5 显示**事后完美动态退出的理论上限极高**
（2.5R：夏普 1.4395 → 13.297），因此失败原因是「模型没学到」，
不是「动态退出没有空间」。
