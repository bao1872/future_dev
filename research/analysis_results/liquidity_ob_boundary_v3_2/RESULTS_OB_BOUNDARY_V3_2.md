## 一、修复了什么

### 修复 1：多周期趋势真正接入

v3.1 的 `attach_trend_multi` 调用的 `SymbolData._trend()` 恒返回
`trend_struct_1h`，而后续代码在找 `trend_struct_5m/15m`，找不到就填
`UNKNOWN` —— 这直接导致 `trend_1h_vs_15m` 有效样本为 0。

v3.2 新增 `build_trend_series(bars, tf)`，**直接从 canonical
`state_timeline` 的 `swing_bias` / `internal_bias` 构建**，绕开旧封装。

### 修复 2：边界三态（不再把"碰边界"当"进入"）

v3.1 用 `D = (ob_margin_R >= 0)`，把 1,100 个 `margin == 0`（恰好碰到
OB near edge）的事件算作"已进入 OB"。v3.2 改为**价格空间严格三态**：

```python
price_delta = extreme - near_edge   # side=+1
              near_edge - extreme   # side=-1
delta < 0  -> NEAR_MISS
delta == 0 -> EDGE_TOUCH      # 严格价格相等，无 ATR 阈值
delta > 0  -> ENTERED_OB
```

| state | n | share |
|---|---:|---:|
| NEAR_MISS | 14,760 | 0.5897 |
| ENTERED_OB | 9,171 | 0.3664 |
| **EDGE_TOUCH** | **1,100** | **0.0439** |

EDGE_TOUCH 数量与 v3.1 的 exact_zero 完全吻合，说明修复正确捕获了这批事件。
**EDGE_TOUCH 不属于左侧、不属于右侧、不进入局部模型。**

## 九、最终分类

```text
C. 无稳定订单块局部增量
```

判 C 而不是 D，因为**本轮总体连续性 Gate 已 PASS**
（max SMD 0.0936、penetration_depth_R 0.0575、分类 5.63pp），
识别条件成立，可以正式解读：

| 条件 | 是否满足 |
|---|---|
| τ 明显 > 0 且 CI 下界 > 0（判 A） | ❌ CI [−0.083, +0.157] |
| 某预注册 subgroup 自身 Gate PASS 且效应稳定（判 B） | ❌ 3 个合格者 CI 全跨 0 |
| **τ 接近 0、CI 跨 0、四带宽一致、合格 subgroup 无正向结构（判 C）** | ✅ |

需要注意的保留：方向上是**一致偏正**的 —— 三态单调
（0.784 → 0.798 → 0.831）、四带宽 τ 全为正、16 个 subgroup 中 10 个为正。
所以准确表述是"**没有稳定的、可统计确认的局部增量**"，
而不是"订单块完全无信息"。以当前样本量，这个正向量级（约 +4pp）
无法与噪声区分。
